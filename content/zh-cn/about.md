欢迎使用 **Markdown Resume** —— 您制作专业简历的得力助手。
我们相信，制作简历应当简单、强大且安全。因此，我们构建了这个工具，
帮助您以完全掌控数据隐私的方式管理您的简历。

## 为什么选择 Markdown Resume？

Markdown Resume 被设计为一款**本地优先应用**，这意味着您的简历、图片
以及所有个人数据都保存在它们应该在的地方——您的设备上。没有云存储，
没有数据挖掘，您的敏感内容绝不会被传输。只有您和您的简历。

无论您是热爱 Markdown 的开发者、需要灵活性的创意专业人士，还是只想
完全掌控求职材料的人，Markdown Resume 都能为您提供创建出色简历的工具。

## 强大功能

别被它的简洁外表骗了——Markdown Resume 拥有强大的功能，帮助您打造完美的简历：

- **多份简历** — 为不同的求职申请创建和管理多份简历
- **实时预览** — 通过实时预览即时查看编辑效果
- **多种导出格式** — 导出为 PDF、HTML 或 MS Word（测试版）
- **图片库** — 上传并管理您的头像和素材
- **全面自定义** — 选择字体、添加图标，随心所欲地设计您的简历
- **数学支持** — 使用 KaTeX 包含数学表达式
- **深色模式** — 在任何光照条件下舒适地编辑
- **离线可用** — 支持 PWA，离线也能正常工作

## 隐私与安全

我们非常重视您的隐私。以下是我们保护您数据的方式：

- **本地存储** — 所有简历内容和图片都存储在您浏览器的 IndexedDB 中，绝不会存储在我们的服务器上
- **无需账户** — 无需注册或登录即可立即开始创建
- **不收集数据（简历）** — 您的简历内容和图片永远不会被收集或传输
- **开源** — 完全透明的代码，您可以审计和贡献
- **您拥有自己的数据** — 随时导出和备份您的简历，控制权始终在您手中

## 数据分析

当您使用托管版本时，我们使用 **Google Analytics** 和 **Cloudflare Web Analytics** 来了解整体使用模式。
这有助于我们通过展示页面浏览量和活跃用户等信息来改进应用。

**重要提示：** 您的简历内容、文档设置和上传的图片*绝不*包含在分析事件中。
我们只收集化名的技术信息，以帮助我们改进应用。
Google Analytics 以化名方式使用，任何简历内容都不会传输给分析服务提供商。
使用托管版本即表示您同意我们的[隐私政策](./privacy/)。
